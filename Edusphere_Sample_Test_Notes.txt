1. FUNDAMENTALS OF DISTRIBUTED LEDGER TECHNOLOGY
Blockchain is a decentralized, distributed, and append-only ledger that maintains an immutable record of transactions across a
peer-to-peer network. Every participant (node) maintains an identical copy of the ledger, eliminating the need for centralized intermediaries.

2. ETHEREUM VIRTUAL MACHINE (EVM) MEMORY & GAS MECHANICS
The Ethereum Virtual Machine (EVM) is a quasi-Turing complete runtime environment that executes smart contract bytecode.
Computational operations require Gas payments to prevent infinite loops and denial-of-service.

3. EIP-1559 TRANSACTION FEE FORMULA
Total Transaction Fee = Gas Units Consumed * (Base Fee + Priority Fee / Tip)
Note: The Base Fee is burned protocol-wide, while the Priority Fee (Tip) goes directly to block validators.

4. SOLIDITY SECURITY, VULNERABILITIES & BEST PRACTICES
Reentrancy Attacks:
Occurs when an external contract call transfers control back to the calling contract before its state (balance) is updated. Defense: Follow the
Checks-Effects-Interactions (CEI) pattern or use OpenZeppelin ReentrancyGuard nonReentrant modifier.
Arithmetic Overflow / Underflow:
In Solidity versions prior to 0.8.0, arithmetic operations silently wrapped around. In Solidity 0.8+, all math operations automatically revert on
overflow unless wrapped in an explicit unchecked { ... } block.
Access Control Flaws:
Failing to restrict administrative functions (e.g. mint, pause, withdraw) allows attackers to drain assets. Defense: Implement strict Ownable or
AccessControl modifiers like onlyOwner.
tx.origin Phishing:
Using tx.origin for authentication allows malicious intermediary contracts to impersonate users. Always authenticate using msg.sender.

6. SAMPLE PRACTICE QUESTIONS FOR TEST EVALUATION
Q1: Which EVM data area consumes the lowest gas for incoming immutable function arguments?
A) Storage   B) Memory   C) Calldata   D) Log Topics
Correct Answer: C (Calldata) | Explanation: Calldata is a read-only byte array allocated for transaction input arguments.
Q2: What is the primary function modifier pattern used to prevent reentrancy attacks in Solidity?
A) Checks-Effects-Interactions   B) Fallback Assembly   C) Tx-Origin Guard   D) DelegateCall Loop
Correct Answer: A (Checks-Effects-Interactions) | Explanation: Updating state balances before external calls stops recursive exploitation.
Q3: In Solidity 0.8+, how does the EVM natively handle arithmetic overflow (e.g. uint256 max + 1)?
A) Silently wraps to zero   B) Reverts transaction automatically   C) Emits warning event   D) Halts block execution
Correct Answer: B (Reverts transaction) | Explanation: Solidity 0.8+ integrates checked arithmetic, triggering automatic Panic(0x11).
